This is a remote

It has no UI of its own; hosts embed what it serves. This one is an island remote built with Vite (examples/vite-remote): it renders React Server Components on its own server and sends each island's HTML to the host that asks for it.

Islands it serves

  • ProductPanel: a product with its price, and −/+ buttons (a client component of the island).
  • Links: links to other products that navigate the host without a page reload.
  • MyOrders: a private island. It renders only with a short-lived token that a host signed for the signed-in user.

See them in a host

  • App Router host (Next.js): all three islands
  • Pages Router host (Next.js, English and French): all three
  • React SPA host (Vite): ProductPanel
