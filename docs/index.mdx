---
title: Welcome to next-federation
description: Runtime UI federation for Next.js. A remote app provides UI that your host app renders at runtime.
---

Embed UI that another team builds and deploys on its own into your Next.js app, without rebuilding the host.

A remote app provides UI that your host renders at runtime. Embed server-rendered islands, or load client components through Module Federation 2.0 into your host's React tree. The library calls only public Next.js APIs.
